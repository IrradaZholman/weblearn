О проекте WebLearn

Визуальная учебная среда для обучения веб-программированию школьников.

Цель проекта

WebLearn создан для того, чтобы школьники могли осваивать основы веб-разработки в удобной визуальной среде. Ученики пишут HTML, CSS и JavaScript и сразу видят результат в превью, что делает обучение наглядным и понятным.

Методика

Используется подход «от простого к сложному»: сначала HTML-разметка, затем стили CSS, затем интерактивность на JavaScript. Каждый урок содержит теорию, примеры и практическое задание с возможностью отправки на ручную проверку преподавателю.

Технологии

Сайт построен на Django и Bootstrap 5. Редактор кода работает в браузере и позволяет экспериментировать с HTML, CSS и JavaScript без установки дополнительных программ.
