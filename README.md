# WebLearn — Визуальная учебная среда для обучения веб-программированию

Дипломный проект: платформа для школьников с курсами HTML, CSS, JavaScript, интерактивным редактором кода и ручной проверкой заданий.

## Технологии

- **Django 4.2** — backend
- **Bootstrap 5** — интерфейс
- **SQLite** — база данных (по умолчанию)

## Установка

```bash
# Создать виртуальное окружение
python -m venv venv

# Активировать (Windows)
venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt

# ВАЖНО: сначала применить миграции (создать таблицы в БД)
python manage.py migrate

# Создать суперпользователя для админки
python manage.py createsuperuser

# Загрузить полный курс с 25 темами
python manage.py create_full_course

# Запустить сервер
python manage.py runserver
```

Сайт будет доступен по адресу: http://127.0.0.1:8000/

## Структура проекта

- **main** — главная, о проекте, контакты
- **courses** — курсы, уроки, задания, тесты, прогресс
- **editor** — интерактивный редактор HTML/CSS/JS с превью
- **accounts** — регистрация, вход, профиль пользователя

## Админ-панель

`/admin/` — управление курсами, уроками, проверка работ учеников, создание тестов.

## Работа с админ-панелью

После создания суперпользователя зайдите в `/admin/` и вы сможете:

1. **Управлять курсами:**
   - Добавлять изображения курсов
   - Добавлять вводные видео (используйте embed URL, например: `https://www.youtube.com/embed/VIDEO_ID`)
   - Редактировать описания

2. **Создавать тесты:**
   - Для каждого урока можно создать тест
   - Для каждого курса можно создать общий тест
   - Добавляйте вопросы с несколькими вариантами ответов

3. **Проверять работы:**
   - Просматривать отправленные работы
   - Ставить оценки (1-5)
   - Оставлять комментарии
   - Менять статус (Принято, На доработку)

4. **Управлять дополнительными заданиями:**
   - Создавать задания разной сложности
   - Они доступны отдельно от уроков

## Структура базы данных

- **Course** — курсы (модули обучения)
- **Lesson** — уроки (темы) в курсах
- **Assignment** — задания к урокам
- **StandaloneAssignment** — дополнительные задания
- **Submission** — работы учеников
- **Quiz** — тесты
- **Question** — вопросы в тестах
- **Answer** — варианты ответов
- **QuizAttempt** — попытки прохождения тестов
- **UserProgress** — прогресс пользователя по урокам/курсам
- **CourseReview** — отзывы о курсах

## Особенности реализации

- Все темы содержат подробный контент с HTML-разметкой, таблицами и примерами
- В каждой теме есть встроенный эмулятор с примером кода
- Редактор поддерживает HTML, CSS и JavaScript с live-превью
- Система прогресса отслеживает выполненные темы
- Тесты можно создавать для уроков и для целых курсов
- Профиль пользователя показывает полную статистику обучения
